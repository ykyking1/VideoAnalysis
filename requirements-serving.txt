#
#     pip install -r requirements.txt      # once ana yigin
#     pip install uv
#     uv pip install -r requirements-serving.txt --torch-backend=auto
#
# NEDEN uv --torch-backend=auto GEREKLİ: Düz `pip install vllm`, vLLM'in en
# güncel PyPI paketini çeker ve bu paket varsayılan olarak CUDA 13 runtime
# kütüphanesi (`libcudart.so.13`) bekliyor - ortamınızdaki torch/sürücü CUDA
# 12.x ise (Colab dahil çoğu ortam) şu hatayla çöküyor:
#
#     ImportError: libcudart.so.13: cannot open shared object file
#
# Bu, vLLM'in kendi paketleme hatası (yukarı akış GitHub issue #43435,
# "not planned" olarak kapatıldı - bilinen, düzeltilmemiş bir sorun).
# `uv pip install --torch-backend=auto`, mevcut CUDA sürücü sürümünü
# tespit edip UYUMLU vLLM ikili paketini seçiyor - vLLM'in resmi
# dokümantasyonunun önerdiği yol (docs.vllm.ai/getting_started/installation/gpu).
#
# LINUX GEREKTİRİR. vLLM'in resmi platform listesinde Windows YOK (NVIDIA CUDA,
# AMD ROCm, Intel XPU, Apple Silicon - hepsi Linux tabanlı). Windows'ta
# `pip install vllm` hazır paket bulamayıp kaynaktan derlemeye çalışır ve
# uzun-yol sınırında başarısız olur (denendi).
#
# Windows'taysanız üç seçenek:
#   1. docker compose --profile gpu up -d vllm    (konteyner Linux, altta WSL2)
#   2. WSL2 içine kurun, host'tan localhost:8000 üzerinden erişilir
#   3. Ayrı bir Linux sunucuda çalıştırıp VLLM_BASE_URL'i ona yönlendirin
